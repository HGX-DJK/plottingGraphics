# GeoPlot Studio - 态势标绘与图层协同系统 (MapTalks GL 版)

基于 **MapTalks GL** 地图引擎开发的态势标绘系统 Web 应用，无需后端服务，采用纯前端本地存储（LocalStorage）驱动，支持军标态势标绘、多图层协同管理、要素属性实时编辑与数据导入导出。

---

## 🌟 系统核心功能

### 1. 免后端用户身份体系 (Mock Auth)
- **快速一键授权登录**：内置多种预置作战角色账号（特级指挥官 `admin`、高级态势分析师 `analyst`、前沿标绘值班员 `operator`）。
- **自定义登录/注册**：支持输入任意用户名及密码，系统自动颁发操作员凭证。
- **状态持久化**：用户凭证保存在本地 LocalStorage，支持随时切换账号与退出登录。

### 2. MapTalks GL 地图引入规范
- **原生 Script / Link 引入**：严格遵照规范，未采用 npm 模块打包地图引擎，直接在 `index.html` 中通过官方 CDN 引入：
  ```html
  <link rel="stylesheet" href="https://maptalks.com/api/maptalks-gl.css" />
  <script type="text/javascript" src="https://maptalks.com/api/maptalks-gl.js"></script>
  ```
- **多底图无缝切换**：
  - 暗夜科技底图 (Carto Dark)
  - 高清遥感卫星影像 (ArcGIS Satellite)
  - 现代街道地图 (Carto Light/Voyager)
  - 态势推演网格 (Tactical Grid)
- **状态栏与量算工具**：
  - 鼠标移动实时显示高精度经纬度坐标（精确到 5 位小数）与地图缩放级别（Zoom）。
  - 大圆球面距离量算工具，支持多段航线累计测距。

### 3. 多图层协同管理体系 (Layer Management)
- **新建图层**：支持自定义图层名称、选择 8 种战术标识色（红方突击红、蓝方防御蓝、保障勤务绿、预警警戒黄等）以及填写图层战术描述。
- **绘制工作层切换**：任意点击选择当前工作图层，后续新建的所有标绘要素自动归属于该图层。
- **独立显隐控制**：点击眼睛图标一键切换图层内所有要素的显示与隐藏。
- **图层锁定保护**：锁定图层后防止误触与误编辑该图层要素。
- **图层透明度平滑调节**：0% ~ 100% 范围滑动条实时调整。
- **要素容量统计与图层删除**：实时统计各图层要素总数。

### 4. 丰富要素标绘工具箱 (Plotting Toolbox)
- **态势战术军标**：
  - **突击进攻箭头 (Attack Arrow)**：战役级宽体突击箭头，支持平滑弧度过渡。
  - **进攻直箭头 (Straight Arrow)**：战术指向箭头多边形。
  - **钳击双箭头 (Pincer Arrow)**：左右两翼钳形夹击包围态势多边形。
  - **战役集结地域 (Gathering Place)**：基于三次贝塞尔曲线拟合的平滑封闭集结区。
  - **防御警戒扇区 (Sector)**：基于圆心和探测方向计算的雷达防空扇形。
- **战术点位标号 (高清 SVG 图标)**：
  - 基本指挥所、雷达探测站、威胁障碍区、野战医疗站、战备机场、物资储备库。
- **基础几何矢量**：
  - 战术标定点、文字注记、机动路线(折线)、控制地域(多边形)、网格搜索区(矩形)、警戒半径(圆形)、态势手绘线。
- **实时绘制交互**：
  - 左键连续打点，鼠标移动时呈现半透明虚线实时跟随预览，达标后自动生成或双击结束绘制，支持 `Esc` 键随时撤回与取消。

### 5. 要素属性配置与交互管理 (Property Inspector)
- **要素列表与搜索**：支持关键字模糊搜索、按所属图层筛选。
- **地图联动聚焦**：在要素列表中点击任意项，地图镜头平滑飞越并定位至该要素。
- **属性实时配置面板**：
  - 修改要素名称与战术任务备注。
  - 重新调整归属图层。
  - 边框线条颜色、线宽粗细（1~10px）、实线/虚线样式。
  - 区域填充颜色、填充不透明度（0~100%）。
  - 注记文本内容、字号大小及文字颜色。
  - 圆形警戒半径（米级调节）。
  - 要素删除。

### 6. 工程数据备份与互通
- **备份工程 (JSON)**：导出包含全部图层与要素的工程备份文件。
- **地理矢量 (GeoJSON)**：导出为标准 GeoJSON 格式，便于接入第三方 GIS 平台。
- **数据导入**：支持将外部备份文件或 GeoJSON 拖拽导入系统。
- **一键恢复演示态势**：内置红方突击、蓝方防御、综合保障三大演训图层与完整标绘要素。

## 🚀 启动与使用指南

### 安装依赖
```bash
pnpm install
```

### 启动开发服务器
```bash
pnpm run dev
```
启动后在浏览器打开 `http://localhost:5173` 即可直接体验。

### 生产打包构建
```bash
pnpm run build
```
编译输出目录位于 `dist/`。
